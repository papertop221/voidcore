**VoidCore Singularity Pro** is the world's most advanced token compression engine for the Gemini CLI. It transforms high-verbosity prompts into high-density **Semantic Opcodes**, allowing developers to save up to **99.9%** on token costs without sacrificing logic, functionality, or context.

## 🚀 Advanced Features

- **Atomic Logic Map (Opcodes)**: Encodes complex architectural patterns (Microservices, JWT, Clean Architecture) into single atomic symbols.
- **Reference Hashing (Content Pointers)**: Replaces previously seen files or large code blocks with a 12-char MD5 hash (`∞:hash`).
- **IndoLeh Pro Engine**: A deep-semantic heuristic compressor for technical Indonesian, removing linguistic noise while preserving technical intent.
- **Syntax-Aware Pro Minifier**: Aggressively compresses code blocks using an AST-lite approach that keeps language keywords (`if`, `await`, `return`) safe.
- **Vowel Strip Singularity**: A radical token-reduction method that packs words into their densest possible form.
