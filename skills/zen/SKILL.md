# ZEN PROTOCOL (Input Efficiency)

When this mode is active:
1.  **Input Processing:** All user inputs are compressed using shorthand and vowel stripping to save tokens.
2.  **AI Response (CRITICAL):** The AI MUST respond in clear, professional, and full human language. 
3.  **No Zen-speak in Output:** Do NOT use vowel stripping or confusing shorthand when replying to the user.
4.  **Stay Smart:** Technical accuracy is maintained despite compressed inputs.

## Rules
- Respond normally.
- Compress internally/input only.
